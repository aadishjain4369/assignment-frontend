# Spezia — frontend

Dashboard for managing webhook subscriptions and viewing inbound events (React, Vite, Ant Design).

## Setup

```bash
npm install
```

Create `.env` if the API is not on the default origin:

```env
VITE_API_URL=http://127.0.0.1:4000
```

## Run

```bash
npm run dev
npm run build
npm run preview
```

Log in or register, then subscribe to sources, copy ingest keys, and watch the live event feed.
